# Changelog

## Unreleased

- Softer body-text contrast and OKLCH chroma limits: no more neon cinnabar, no more 14:1 glare.
- Insertion caret now uses the flavor's cool interaction color instead of the keyword red.
- Dimmed variants deepen the canvas instead of washing it grey; ink stays at ≥10.5:1 and pigments keep their hue.

## 0.3.0

- New blue-green family: **沧海 Canghai** (dark) and **青瓷 Qingci** (cool light), inspired by 青绿山水, 海青 / 霁青 and celadon glaze.
- Six variants total: 玄墨, 玄墨 Dimmed, 宣纸, 宣纸 Dimmed, 沧海, 青瓷.
- Workbench, TextMate and semantic token colors now cover all six variants.
- The preview page groups the ink-and-paper and sea-and-celadon families.
- 480 WCAG contrast checks (up from 320).

## 0.2.0

- New **Dimmed** variants: **玄墨 Dimmed** (dark) and **宣纸 Dimmed** (warm light) — lower saturation and softer canvases while keeping the same contrast floors.
- Four themes total: 玄墨, 玄墨 Dimmed, 宣纸, 宣纸 Dimmed.
- 320 contrast checks (up from 160).

## 0.1.0

- First release.
- Two flavors: **玄墨 Xuanmo** (dark) and **宣纸 Xuanzhi** (warm light), built from the 526-color zhongguose palette.
- 443 workbench colors, 35 TextMate rules, 28 semantic token categories.
- Build-time contrast audit (160 checks) and a generated palette reference.
