## 设计原则

1. **以墨为底**：暗色画布沿用「暗龙胆紫」的色相压暗，亮色画布直接使用「鱼肚白」。
2. **以矿物颜料为彩**：关键字取朱砂系、字符串取铜绿、类型取姜黄或桔梗紫，颜色名称本身可追溯。
3. **同一骨架**：两个变体的色相顺序一致（红 → 蓝 → 绿 → 橙 → 黄 → 青 → 紫 → 绛），切换时只换光线。
4. **可读性优先**：正文 ≥ 7:1，语法色 ≥ 4.5:1，注释与标点 ≥ 3:1；终端黄色/白色按纸面特性单独放宽。
